Design a modern web app UI for a secure communication platform called AegisNet.

Product concept:
AegisNet is a secure communication platform that feels organized like Discord servers but does not look or feel like Discord. It should feel private, clean, and simple like Signal when users are messaging, calling, video calling, or using group chats. The app is for families, teams, student organizations, emergency response groups, cyber teams, field operators, and normal users who need reliable communication.

Overall design style:
Create a calm, secure, modern dark-mode interface.
The app should feel trustworthy, clean, fast, and professional.
Avoid gamer styling.
Avoid a corporate Microsoft Teams look.
Avoid clutter.
Use a dark navy and charcoal background, soft gray panels, clean white text, blue highlights, green verified indicators, yellow weak-signal indicators, and red only for emergency alerts.
Use rounded cards, simple icons, clean spacing, and a modern layout.

Call screen design:
Create a group video call screen for AegisNet.
The call should feel like Signal group video, but with better operational status.
Show video tiles for six users.
One user tile should say “Reconnecting…”
Another should show “Audio only, weak signal.”
Another should show “Low bandwidth mode.”
Include buttons:
Mute
Camera
Screen share
Chat
Raise hand
End call
Switch to low bandwidth
Invite user

Important reconnect feature:
Show a reconnect banner at the top of the call:
“Connection lost. Trying to reconnect you to the call…”
Also show:
“Your video will return automatically when signal improves.”
Design the system so the user stays in the call room while reconnecting.
If video fails, show fallback to audio only.
If audio fails, show fallback to live text updates.
Use a simple connection quality meter.

Important UI rules:
Do not use the word “server.”
Use “Network” instead.
Do not make it look like a Discord clone.
Use Discord only as inspiration for organization.
Use Signal as inspiration for messaging, calls, privacy, and simplicity.
Keep advanced tools available but not overwhelming.
Make the app feel simple for normal users and powerful for professional teams.
