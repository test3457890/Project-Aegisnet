YOUR NODE DETAILS
Fill in before starting
Fill these in — the guide will use them throughout.
These are stored in your browser only. Nothing is sent anywhere.
1
FLASH RASPBERRY PI OS
Required
Download Raspberry Pi Imager and flash to a 32GB+ A2 microSD.
✓ OS: Raspberry Pi OS Lite (64-bit, Bookworm)
✓ Gear icon → set hostname, username, Wi-Fi, enable SSH
✓ Hostname: aegisnet-node (or your choice)
✓ Enable SSH with password or public key
2
CONNECT OVER SSH
Required
From your laptop terminal:
ssh pi@aegisnet-node.local
If mDNS doesn't work, use the IP address directly. Find it in your router's device list.
3
COPY THE P4.4 PACKAGE
Required
From your laptop (not the Pi), in the folder where you unzipped the package:
scp -r ./skymesh-scout-p4.4 pi@aegisnet-node.local:/home/pi/
Or use FileZilla / Cyberduck if you prefer a GUI. Target path: /home/pi/skymesh-scout-p4.4/
4
RUN THE INSTALLER
Required
On the Pi (in your SSH session):
cd /home/pi/skymesh-scout-p4.4
chmod +x deploy/install.sh
sudo ./deploy/install.sh
The installer will ask two yes/no questions with 15-second timeouts:
· Install readsb (ADS-B)? → Y if you have the RTL-SDR plugged in, N otherwise
· Install rtl-ais? → N unless you have a second SDR for AIS
Expected final output:
  Dashboard:  http://[YOUR_PI_IP]:8080
  Setup wizard: http://[YOUR_PI_IP]:8080/setup
5
COMPLETE SETUP WIZARD
Required
Open this URL from your phone or laptop (must be on same Wi-Fi):
http://aegisnet-node.local:8080/setup
Five steps: Node Identity → MQTT/Mesh → Tracking → Access → Acknowledgments
The wizard generates your node ID and saves config to the Pi.
6
CONNECT HARDWARE
Connect available hardware
T-Beam connects directly to Pi USB, not through the hub. SDR dongles go through the powered hub.
Verify readsb sees the SDR (on the Pi):
systemctl status readsb
# If not installed:
ls /run/readsb/aircraft.json
7
DASHBOARD VERIFICATION
Open from phone or laptop
Open the dashboard — check these items:
http://aegisnet-node.local:8080
