# Build Checklist

Create a checklist that must be completed before an update is considered finished.

* Project runs locally.
* No TypeScript errors.
* No broken imports.
* Navigation works.
* Theme picker changes the whole app.
* Warm Everyday theme exists if already requested.
* Mock data stays separated from JSX if already completed.
* No backend added by mistake.
* No real auth added by mistake.
* No real encryption added by mistake.
* No AI added by mistake.
* No external Unsplash image dependency remains if already removed.
* UPDATE_LOG.md updated.
* CURRENT_STATE.md updated if needed.
* NEXT_STEPS.md updated if needed.
* LESSONS_LEARNED_FROM_AMI.md updated if the task touches architecture, installers, release packaging, diagnostics, RBAC, MFA, AI, or desktop launch behavior.
